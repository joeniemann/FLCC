# Standalone hero study — superseded

This was the single-file hero we iterated on before the full site existed.
It is kept because it is a clean, self-contained demo of the Cut & Sewn mark.

**It is no longer the source of truth.** The live hero is:

- markup  → `src/partials/hero.html`
- styles  → `assets/css/hero.css`
- script  → `assets/js/hero.js`
- photos  → `assets/hero/`

Editing `hero.src.html` will not change the website. Build with
`bash tools/build-site.sh` instead.

`build-hero.sh` only rebuilds this archived study and expects the two
JPEGs sitting beside it.
