◀ Cut  —  drag to move the seam  —  Sewn ▶ One outline, two tools

What's happening in the mark

A single traveller runs the FLCC mark's contours. Which tool it is depends on which side of the seam it is currently on — so the fabrication half is genuinely being torch-cut while the upholstery half is genuinely being sewn, by the same pass.

Fabrication side

Cut in the right order

The torch takes F, L, C, C first and the ring last — every inner feature before the outline, the way a CNC sequences a cut so the part doesn't drop free early. Sparks throw from the tip; the kerf stays molten behind it.

Upholstery side

Stitches accumulate

The needle lays a running stitch along the identical contour, riding the path's tangent, revealed through a mask that grows with the pass. The thread stays where it was laid rather than sweeping through.

The handoff

The tool changes at the seam

Cross the seam mid-contour and the needle becomes a torch, or the reverse. Drag the seam to set the balance: pull it right and the mark is almost entirely sewn; pull it left and it's almost entirely cut.
